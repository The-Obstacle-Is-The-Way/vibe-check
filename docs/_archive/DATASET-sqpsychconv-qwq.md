# Dataset Card: SQPsychConv QwQ

**Source**: `AIMH/SQPsychConv_qwq` (HuggingFace)

**Verified**: 2026-01-02
**Status**: DATA INTEGRITY ISSUE DETECTED

---

## Summary

SQPsychConv is a synthetic psychotherapy conversation dataset generated by AI models. The QwQ variant uses the Qwen QwQ model for both client and therapist roles.

---

## Critical Data Integrity Issue

### Train/Test Split Duplication

**CONFIRMED**: Train and test splits are **100% identical**.

| Evidence | Result |
|----------|--------|
| test_sample.csv MD5 | `3c2df10fa846d6c6128bf2f90e7822bb` |
| train_sample.csv MD5 | `3c2df10fa846d6c6128bf2f90e7822bb` |
| test Arrow MD5 | `e3ff92d039b8ee12fa2023fc4d3abfb3` |
| train Arrow MD5 | `e3ff92d039b8ee12fa2023fc4d3abfb3` |
| file_id overlap | 2,090 / 2,090 (100%) |
| dialogue hash overlap | 2,090 / 2,090 (100%) |
| num_bytes (both splits) | 12,822,790 |

**Impact**: The HuggingFace page claims 4,180 total examples (2,090 train + 2,090 test), but there are only **2,090 unique dialogues**. The upstream dataset appears to have a publishing bug where the same data was uploaded to both splits.

**Mitigation**: Implemented in `src/vibe_check/data/corpus.py`:
- Ignore HuggingFace split labels entirely
- Use deterministic SHA256-based resplitting on `file_id`
- See SPEC Section 3.4 for implementation

## Data Quality Checks

### Implemented Checks

1. **file_id uniqueness**: 0 duplicates within each split
2. **Dialogue deduplication**: SHA256 hash verification confirms no internal duplicates
3. **Split leakage check**: 100% overlap (FAILED - upstream bug)
4. **Speaker parsing**: Dialogues use "Therapist:" and "Client:" labels consistently

### Recommended Preprocessing

1. Load only `train` split (or either - they're identical)
2. Apply deterministic resplit using `compute_split(file_id)`
3. Extract dialogue views per SPEC Section 5.3

### Deterministic Resplit Results
